# Trabajo Final - Curso de Python

Este repositorio contiene los tres ejercicios del trabajo final.

## Archivos

1. **ejercicio_1_sensores.py**: limpieza de registros de sensores y resumen estadistico de temperaturas.
2. **ejercicio_2_inventario.py**: clases, herencia, excepciones personalizadas y guardado de datos en formato JSON.
3. **ejercicio_3_emisiones_django.py**: calculo de emisiones de carbono, metricas de consumo, pruebas unitarias y una vista de Django.

## Ejecucion

Los ejercicios 1 y 2 se pueden ejecutar con Python desde la terminal:

```bash
python ejercicio_1_sensores.py
python ejercicio_2_inventario.py
```

Para ejecutar las pruebas unitarias del ejercicio 3:

```bash
python ejercicio_3_emisiones_django.py
```

La vista de Django requiere estar integrada en un proyecto Django configurado.
